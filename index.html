      ③ 直接用 STOP ID 新增

      STOP ID 可喺站牌／政府 API 直接搵到，適合已知 ID 嘅進階用法。

      ④ 地鐵（港鐵）搜尋

      打站名、英文或站碼（亦可揀一條綫瀏覽沿綫車站）→ 按「選擇方向」→ 揀上行或下行才加入。支援 10 條重鐵路綫。

        ⑤ 我的路線

          主頁會顯示：路線號碼 → 目的地／方向 → 上車站 → 未來 3 班到站時間。

          ⑥ 我的地鐵站

            主頁每項只佔一行：車站名 → 路綫／方向（往 XXX）→ 最近 3 班。想改方向按「改方向」。

            ⑦ 我的巴士站

              點路線chip可選擇只顯示邊條線；唔揀＝顯示全部途經路線（每條線最多 3 班）。

              ⑧ 顯示設定

              data.etabus.gov.hk
              巴士資料：data.gov.hk「資料一線通」九巴／龍運實時到站 API（每分鐘更新）
              地鐵資料：data.gov.hk 港鐵 Next Train API（每分鐘更新）
              天氣資料：data.gov.hk 氣象分類 →「本港地區天氣報告」
              本頁純前端運作，無後端、無追蹤，設定只存在你部裝置。
